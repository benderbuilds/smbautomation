## Issues Not Fixed (Requiring Manual Attention)

### P1

- **TypeScript build failure** (`Invalid value for '--ignoreDeprecations'`): Pre-existing issue in tsconfig or Next.js configuration. `ignoreDeprecations` value "6.0" is not a valid TypeScript option — valid values are `"5.0"` for TS 5.x. Check `tsconfig.json` and verify the TypeScript version with `npx tsc --version`. Fix: change `"ignoreDeprecations": "6.0"` to `"ignoreDeprecations": "5.0"` or remove it if no longer needed.

### P2

- **`mvp-development-cost` topical relevance**: This post about MVP development costs is off-brand for a service business automation site. It appears in the blog feed and dilutes topical authority for SMB automation. Consider gating or noindexing if it's not generating traffic.
- **Blog index page title**: `app/(site)/blog/page.tsx` uses `title: 'Business Automation Blog'` — could be improved to `'Small Business Automation Blog | SMB Automation'` for brand + keyword association.
- **Image `alt` text**: No post images were audited. Ensure any images in posts have keyword-relevant alt text for Google Image and GEO signal purposes.

### P3

- **dateModified missing from BlogPosting JSON-LD**: The schema outputs `datePublished` only. Adding `dateModified` (using the post date or a tracked last-edit date) would improve freshness signals for GEO.
- **`@id` property missing from Organization schema**: Adding `"@id": "https://smbautomation.io/#organization"` enables proper entity disambiguation for knowledge graph association.
- **Breadcrumb JSON-LD missing from post pages**: A `BreadcrumbList` schema on post pages helps AI assistants understand site hierarchy and improves rich results eligibility.

## Recommendations for Next Sprint

1. **Fix the TypeScript build failure** (P1) — change `"ignoreDeprecations": "6.0"` to `"5.0"` in tsconfig.json. This is blocking clean deploys.

3. **Add `@id` to Organization schema** in `app/(site)/page.tsx` for knowledge graph entity binding.
4. **Add BreadcrumbList JSON-LD** to the blog post page for rich results and GEO hierarchy signals.
