## Issues Found and Fixed

### 1. `app/(site)/page.tsx` — Missing Organization JSON-LD schema (FIXED)

**Issue:** The homepage had a `Service` schema but no `Organization` schema, which is important for GEO (AI assistants use Organization schema to identify and cite named entities).

**Fix:** Added `organizationSchema` object and corresponding `<Script id="organization-schema">` tag:
```json
{
  "@context": "https://schema.org",
  "@type": "Organization",
  "name": "SMB Automation",
  "url": "https://smbautomation.io",
  "description": "Business efficiency audits and automation consulting for established small and mid-size businesses."
}
```
