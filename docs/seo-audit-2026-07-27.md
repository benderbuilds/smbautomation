### P2 — Recommended for Next Sprint

- **Audit script regex**: The internal audit script used a regex pattern `[\"\'](.*?)[\"\']` to extract excerpts, which fails on excerpts containing apostrophes (matching the apostrophe as a closing delimiter). This caused three over-length excerpts to persist undetected for several weeks. Recommend replacing with a double-quote-only pattern or a proper YAML parser for future runs.

---

## Audit Script Notes — Known Limitation Fixed

The previous audit regex (`re.search(r'^excerpt:\s*[\"\'](.*?)[\"\']', ...)`) treated `'` as a quote delimiter, stopping early on strings containing apostrophes (e.g., "Here's", "don't"). Posts such as `flooring`, `handyman`, and many others with apostrophes in excerpts were silently passing length checks. This audit corrected the check and found three violations. Future runs use the corrected pattern `r'^excerpt:\s*\"(.*?)\"'` (double-quote only, DOTALL).
