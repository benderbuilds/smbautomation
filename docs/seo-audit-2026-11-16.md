## Recommendations for Next Sprint

### P2 — Moderate priority

1. **Sitemap `lastModified` precision**: Posts use `new Date(post.date)` which only has day granularity. For the homepage and blog index, `new Date()` returns the build time. If posts are updated without changing their `date` field, Googlebot may not detect the update. Consider tracking a `lastModified` or `updatedAt` frontmatter field for posts that get content revisions.

2. **Blog index Open Graph tags**: `app/(site)/blog/page.tsx` sets `title` and `description` metadata but no explicit `og:image`. Adding a generic OG image for the blog index would improve click-through from social shares.

3. **seoTitle field in blog index cards**: The blog index (`/blog`) renders cards using `post.title`, not `post.seoTitle`. Since `seoTitle` is intended as the keyword-optimized version of the title, consider whether the card should display `post.seoTitle` or `post.title`. Currently these are different values in many posts and consistency would help AI summarization.

### P3 — Low priority / Future sprint

4. **Author schema enhancement**: The JSON-LD `BlogPosting` schema uses `Organization` as author type. Some AI assistants prefer `Person` as `author` for content credibility signals. Consider adding an `author` Person entity if a byline person is ever associated with posts.

5. **BreadcrumbList schema**: Adding JSON-LD `BreadcrumbList` to blog post pages (`Home > Blog > [Post Title]`) is a quick win for both Google rich results and AI citation context.

6. **`dateModified` in BlogPosting schema**: The JSON-LD currently only sets `datePublished`. Adding `dateModified` (even if same as `datePublished` initially) signals freshness to AI indexers.
