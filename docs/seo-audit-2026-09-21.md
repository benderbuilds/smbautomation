## Phase 3 — Issues Not Fixed (Manual Attention Required)

### P2 — Recommended for Next Sprint

- **Blog index page (`/blog`) has no schema markup**: Consider adding `ItemList` JSON-LD to the blog index listing all posts. This helps AI assistants surface the blog as a structured content collection.
- **No `dateModified` in BlogPosting schema**: Currently only `datePublished` is included. Adding `dateModified` (from a frontmatter field or file mtime) would improve freshness signals for both Google and AI engines.
- **No `image` in BlogPosting schema**: AI assistants and social previews benefit from an `image` field in the JSON-LD. Adding a default OG image per post (or a site-wide fallback) would fill this gap.
- **No `wordCount` or `articleBody` in BlogPosting schema**: Optional but beneficial for GEO — helps AI engines assess content depth.

### P3 — Low Priority / Optional

- **`seoTitle` missing `| SMB Automation` brand suffix on some posts**: The brand isn't appended to post title tags. This is a style choice but consistent brand presence in title tags helps with entity association in AI engines.
- **No internal links to the homepage (`/`) from blog posts**: While posts link to `/#contact`, adding one link to the homepage itself from at least a few cornerstone posts can improve homepage authority signals.
- **No blog post covers "what is SMB Automation" or a branded FAQ post**: A cornerstone "About SMB Automation" or "What is SMB Automation?" post would dramatically improve entity recognition in AI assistants.
