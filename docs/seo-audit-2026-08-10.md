### P3 — Lower Priority / Recommendations

**Schema: `image` field missing from BlogPosting JSON-LD**  
Google's documentation recommends an `image` property on BlogPosting for rich results eligibility. Currently the schema is valid but omits image. Requires either a per-post `ogImage` frontmatter field or a default fallback image URL. Recommend adding in the next sprint.

**Blog index `og:image` missing**  
`app/(site)/blog/page.tsx` has no `openGraph.images` in its metadata export. Add a default blog cover image for social sharing cards.

**Homepage: `sameAs` missing from Organization schema**  
Google recommends `sameAs` pointing to authoritative profiles (LinkedIn, Twitter/X, etc.) for better entity disambiguation by search engines and AI assistants. Add to `organizationSchema` in `app/(site)/page.tsx` once social profiles are live.

**Breadcrumb schema not present on blog posts**  
Adding a BreadcrumbList JSON-LD alongside the BlogPosting schema improves sitelinks rendering in Google results. Low effort, measurable impact for navigational queries.

## Recommendations for Next Sprint

1. **Add `image` field to BlogPosting schema** — Create a default OG image (1200×630) and reference it as the fallback `image` in `blog/[slug]/page.tsx`. Per-post images via frontmatter `ogImage` as an optional override.

2. **Add `og:image` to blog index page** — One-line addition to the `metadata` export in `app/(site)/blog/page.tsx`.

3. **Add `sameAs` to Organization schema** — Once LinkedIn/social profiles are published, link them in the homepage `organizationSchema` for entity disambiguation.

4. **Add BreadcrumbList schema to blog post renderer** — Structured `Home > Blog > [Post Title]` breadcrumb improves Google SERP rendering.

5. **Monitor GEO citation rate** — Search Perplexity and ChatGPT for target queries ("small business automation consultant", "how to automate a plumbing business", etc.) to track whether smbautomation.io appears in AI-sourced answers. FAQ sections and SMB Automation entity mentions added this sprint are the primary levers for citation frequency.
