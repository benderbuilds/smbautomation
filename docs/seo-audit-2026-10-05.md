## Issues Not Fixed — Manual Attention Required

### P2 — `ctaType` frontmatter missing from ~60 posts

~60 of 82 blog posts do not have a `ctaType` frontmatter field. `lib/posts.ts` defaults to `'broad'` when missing, so this is not a production error. Explicit `ctaType` makes CTA strategy intentional and auditable.

**Recommendation:** Add `ctaType: "workflow"` or `ctaType: "broad"` to all posts. Workflow-specific automation posts (estimate follow-up, appointment reminders, invoice follow-up) should use `"workflow"`; broader strategy and playbook posts should use `"broad"`.

### P3 — `dateModified` uses `datePublished` as fallback

`dateModified` was added to the JSON-LD this run, but currently equals `datePublished` for all posts. Search engines and AI assistants use `dateModified` to assess freshness. Posts that have been updated should have an accurate `dateModified`.

**Recommendation:** Add an optional `lastModified` frontmatter field to `lib/posts.ts` → `PostMeta`. Update `app/(site)/blog/[slug]/page.tsx` to use `dateModified: post.lastModified ?? post.date`. When any post's body is substantially updated, set `lastModified: "YYYY-MM-DD"` in its frontmatter.

### P3 — No `image` / `og:image` in post frontmatter

Open Graph posts lack post-specific `og:image` tags beyond the auto-generated `opengraph-image.tsx`. Custom OG images per post would improve social sharing click-through rates and GEO citation richness.

**Recommendation:** Add an `image` frontmatter field and reference it in `generateMetadata` in `app/(site)/blog/[slug]/page.tsx` for post-specific OG image URLs.

### P3 — `FAQPage` schema not present on posts with FAQ sections

All 82 posts have a FAQ section, but the JSON-LD only outputs `BlogPosting`. Adding `FAQPage` schema alongside `BlogPosting` could capture "People also ask" and featured snippet placements.

**Recommendation:** Extend `app/(site)/blog/[slug]/page.tsx` to output a second JSON-LD block of type `FAQPage` with `mainEntity` items parsed from each post's FAQ section. This requires either a MDX parsing step or a structured `faqs` frontmatter array.

## Recommendations for Next Sprint

1. **Add `lastModified` frontmatter field** — Extend `PostMeta` in `lib/posts.ts` and update the `BlogPosting` JSON-LD to use it as `dateModified` when present, falling back to `datePublished`.

2. **Add explicit `ctaType` to all posts** — Remove reliance on the default fallback; make CTA strategy visible in frontmatter for all ~60 posts currently missing it.

3. **Implement `FAQPage` structured data** — For posts with FAQ sections, supplement `BlogPosting` with `FAQPage` JSON-LD to target featured snippet and "People also ask" placements.

4. **Add post-specific OG images** — Using `next/og` and the existing `opengraph-image.tsx` pattern, generate per-post social images that include the title and brand treatment.

5. **Evaluate adding more AI bot rules to `robots.ts`** — Consider explicit `allow` rules for `Anthropic-AI`, `YouBot`, and `BingBot` for complete AI crawler coverage.
