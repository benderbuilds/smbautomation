### P3 (Low Priority / Future Sprint)

- **Sitemap `lastModified` dates are dynamic (`new Date()`)** for homepage and `/blog` index — consider pinning these to the last-edited date of the respective files for more accurate signals to crawlers.
- **`og:image` not explicitly set** in `app/blog/[slug]/page.tsx` — the site relies on the opengraph-image route (`/blog/[slug]/opengraph-image-fx5gi7`) for dynamic OG images. This is fine but should be confirmed as rendering correctly for each post type in production.
- **Blog index page (`app/(site)/blog/page.tsx`)** does not output JSON-LD (e.g., `ItemList` or `CollectionPage`). Not critical but could improve AI agent indexing of the blog as a collection.
- **`app/(site)/blog/page.tsx` title** is `"Business Automation Blog"` — consider a more keyword-rich title like `"Small Business Automation Blog | SMB Automation"` for better brand association.
- **New posts in the future** should be added to the bottleneck-audit linking paragraph as part of the publishing workflow, to avoid repeat orphan accumulation.

## Recommendations for Next Sprint

1. **Add `CollectionPage` JSON-LD to `/blog`** — helps AI assistants index the blog as a structured collection. Low effort, GEO value.
2. **Add a `sameAs` array to the Organization schema** in `app/(site)/page.tsx` pointing to Google Business Profile URL, LinkedIn, and any social profiles — strengthens entity recognition.
3. **Review the bottleneck-audit paragraph length** — it now links to 40+ posts in a single paragraph. Consider splitting into a structured list or table for readability and crawlability.
4. **Confirm OG image rendering** for all 85 blog posts in production — the dynamic image route is set up but not audited for visual accuracy.
5. **Pin `lastModified` in sitemap.ts** for key pages using file system mtime rather than `new Date()`.
