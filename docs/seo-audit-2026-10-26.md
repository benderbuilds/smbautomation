## Recommendations for Next Sprint

### P1 (High impact, do next)

1. **Spot-check keyword in H1/first-100-words on lower-traffic posts** — The audit confirmed structure (seoTitle, excerpt, FAQ, links) on all posts but did not run a full H1 keyword-match pass across all 85 posts. A scripted check comparing `title` field to the post's slug keywords would catch any title/keyword mismatches. Estimated effort: 2 hours.

2. **Add `dateModified` to BlogPosting JSON-LD** — Currently only `datePublished` is emitted. Google and AI crawlers use `dateModified` as a freshness signal. Adding it requires surfacing a `updatedAt` field in frontmatter (even if it defaults to `datePublished`) and passing it to the JSON-LD output in `app/(site)/blog/[slug]/page.tsx`. Estimated effort: 1 hour.

### P2 (Medium impact, next 30 days)

3. **Breadcrumb JSON-LD** — Add `BreadcrumbList` schema to blog post pages (`Home > Blog > [Post Title]`). AI assistants and Google use breadcrumb schema to understand site hierarchy. Can be added to the same `<script>` block in `app/(site)/blog/[slug]/page.tsx`. Estimated effort: 1 hour.

4. **FAQPage JSON-LD** — All 85 posts already have FAQ sections. Emitting `FAQPage` schema alongside `BlogPosting` on each post would make the Q&A directly eligible for Google's FAQ rich results and improve AI citation eligibility. Requires parsing the FAQ section from MDX or adding structured FAQ frontmatter. Estimated effort: 4–6 hours.

5. **Review high-link-count hub posts for link equity dilution** — `bottleneck-audit` now links to 40+ posts. While this is valuable for crawlability, extremely high outbound link counts dilute the PageRank passed to each destination. Consider whether some links could move to a dedicated "Related Posts" component at post level rather than inline prose. Estimated effort: 2 hours design, implementation varies.

### P3 (Lower priority, next quarter)

6. **Open Graph images per post** — The current `opengraph-image.tsx` exists at the slug level but uses a generic template. Post-specific OG images with the post title rendered in would improve click-through rates from social shares and AI link previews. Estimated effort: 8–12 hours.

7. **Canonical review for paginated or filtered blog views** — If tag filtering or pagination is added to `/blog` in the future, canonical tags will need to be set correctly to avoid thin content issues. No action needed now.
