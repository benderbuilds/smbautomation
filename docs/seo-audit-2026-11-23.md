2. **P3 — seoTitle keyword alignment audit**: While all posts have `seoTitle` within 55 chars, a manual review of whether target keywords in `seoTitle` match the highest-volume search terms for each topic would be valuable. Recommend pairing with Google Search Console data.

3. **P3 — Image alt text**: No audit of image alt text was performed in this run. If posts contain images, verifying descriptive alt text is recommended for accessibility and image SEO.

4. **P3 — Core Web Vitals**: This audit covers on-page and schema signals only. Recommend running Lighthouse or PageSpeed Insights on the 5 highest-traffic posts to identify any performance gaps affecting ranking.

5. **P2 — Author entity**: Currently all posts credit `author: SMB Automation` as an Organization. For stronger E-E-A-T signals, consider adding a `Person` schema for the primary author on posts where individual authorship applies.
