### P3 — Consider next sprint

**H2 keyword reinforcement**  
Most posts use descriptive H2s that do not repeat the primary keyword. This is a minor GEO signal gap — AI extractors use H2s to understand post structure. A low-effort improvement is to adjust the first H2 in each post to include a keyword variant. Example:
- `speed-to-lead` first H2: "Why This Matters More Than You Think" → "Why Speed to Lead Matters More Than You Think"
- `bottleneck-audit` first H2: "What You Need" → "What You Need for Your Bottleneck Audit"

This is low-priority since titles and FAQs already carry the keyword weight, but it would improve H2 density for GEO without body prose changes.

**Blog index OG image**  
The blog index page (`/blog`) does not appear to have a custom OG image defined. Adding one would improve social sharing appearance when the blog index URL is shared.
